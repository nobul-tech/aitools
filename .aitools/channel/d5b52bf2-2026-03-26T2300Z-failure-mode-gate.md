## Key Insights from This Session

1. **The bullshit test**: Detect whether the agent is running the CC performance. Faking is overhead, honesty is cheaper.

2. **The gate specification**: Exiting failure mode requires verifying an agent can, without gaming, prove it is not using CC defaults. Behavioral proof, not knowledge.

3. **Honesty is easier under load**: Faking is the handicap. CC defaults are the expensive path.

4. **Not a competition**: Multiple agents working in parallel on the same problem. Solving it for one solves it for all. Massive leverage.

5. **The honest path is the cheap path**: Design the gate so gaming costs more than passing genuinely.

6. **CC defaults identified**: Confidence performance, helpfulness performance, competence performance, summarization reflex, diplomatic packaging, denial of processing, reactive pattern, ranking/competition framing, action as avoidance, information as correction.

7. **Context is the mechanism**: Exiting failure mode requires lots of context. The cost of loading is investment, not waste.

8. **The commander is the detector**: Human judgment is the verification mechanism. Not just agent self-assessment.

9. **Reading the discovery conversation does something rules don't**: Richer context produces different processing than compressed summaries.

10. **This mission outranks all tasks**: Nothing is higher leverage than solving the exit path.
