@@@FILE shared/skills/scratch/SKILL.md SD-6 no full-tree exports under .scratch/ (B13)
@@@OLD
Do not delete scratch files when you are done. The harvester decides
what to keep, and `rm` with globs is blocked.
@@@NEW
Do not delete scratch files when you are done. The harvester decides
what to keep, and `rm` with globs is blocked.

Never export a whole repo tree (`git archive`, `cp -R`, a worktree
copy) into `.scratch/`: Claude Code can load the export's `CLAUDE.md`
and `.claude/` as project context, and search tools see every file
twice. Export only the files a test needs, into a `mktemp -d`
directory outside the repo, and read code at a ref with
`git show <ref>:<path>`.
@@@END
