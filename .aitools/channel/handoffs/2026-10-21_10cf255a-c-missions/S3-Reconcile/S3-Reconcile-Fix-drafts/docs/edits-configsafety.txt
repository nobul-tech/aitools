- **Markdown files and shell scripts**: `deploy_managed_file` calls
  `backup_file` internally — callers need not call it separately

- **Files the managed-file library writes** (`deploy_managed_file` /

  caller MUST call `backup_file` / `Backup-File` before the merge write
@@@END
@@@FILE .claude/rules/config-file-safety.md D180b a failed backup stops a deploy_managed_file write (protected)
@@@OLD
Backup failures are non-fatal (warn and proceed) — a failed backup should not
block deployment. A merge or copy without backup is a bug.
@@@NEW
A failed backup in a script's own write, and in `sync_managed_json` /
`Sync-ManagedJson`, is non-fatal (warn and proceed). In `deploy_managed_file` /
`Deploy-ManagedFile` it stops that file: nothing is written, the error is
logged and the file is reported as ERROR (`@.claude/rules/agentic-standards.md`
"Managed-file review choices and merge", failure handling). A merge or copy
without backup is a bug.
@@@END
