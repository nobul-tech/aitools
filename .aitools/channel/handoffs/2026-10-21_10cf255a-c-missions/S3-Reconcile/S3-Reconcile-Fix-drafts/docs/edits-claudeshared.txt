- **Note**: Claude Code on Windows runs its Bash tool in Git Bash from Git for Windows (set `CLAUDE_CODE_GIT_BASH_PATH` in settings.json if it is not found); without Git for Windows it uses the PowerShell tool instead, and with it the PowerShell tool is available alongside Bash (on by default for claude.ai and Console accounts; `CLAUDE_CODE_USE_POWERSHELL_TOOL=0` turns it off). Source: code.claude.com/docs/en/setup, read 2026-10-26. `CLAUDE_CODE_SHELL` was reported broken on Windows ([#25558](https://github.com/anthropics/claude-code/issues/25558); not re-checked). The harness assumes Git Bash: use Unix shell syntax in the Bash tool. To run PowerShell from it: `pwsh -NoProfile -Command '...'`
