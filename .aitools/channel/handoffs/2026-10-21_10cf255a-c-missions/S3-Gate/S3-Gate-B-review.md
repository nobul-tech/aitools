# S3-Gate-B review: tool support decision tree rev 3, cross-platform and bootstrap lens

**Intent**: **Purpose**: Give the commander and mission S3-Gate a rated list of defects in decision tree rev 3 that appear only on a specific platform, shell, or bootstrap state, with evidence, so rev 4 can fix the blockers and majors before the gate. **Scope**: APFS case sensitivity (S4-9), PowerShell and Windows paths, `/bin/bash` 3.2 on macOS, the first run without node, exit 2 = user abort and the RP guard, Git Bash vs WSL bash. NOT rule-correctness findings that hold on every platform (S3-Gate-A). NOT the sibling drafts. NOT filing incidents. **Audience**: S3-Gate (writes rev 4), the session commander, the commander at the gate.

## Summary

1. 15 findings: 1 blocker, 5 majors, 9 minors. I checked behaviour on this Mac with probes (`/bin/bash` 3.2.57). Windows behaviour is from reading code and rules only, not from running it.
2. The blocker is B-01: exit 2 is not unique to user abort. Under `set -e`, bash exits 2 for any command that returns 2 (grep, diff, a helper's rc 2) and for a syntax error in a sourced file. Under §7.5 the installer would stop the whole run and print "aborted by user" for ordinary failures, including a malformed generated tool spec.
3. The majors:
   - B-02: the bash 3.2 rule misses two crashes, empty arrays under `set -u` and `${x,,}`.
   - B-03: on Windows, PATH resolution of `bash` finds WSL, which conflicts with the managed-bash rule.
   - B-04: the PS1 realpath resolves only the last path component, so nvm-windows is misclassified.
   - B-05: §7.6 has no PowerShell shape, and a PS function's return value is polluted by its output.
   - B-06: if `build-deploy.sh` runs the spec generator, `aitools` cannot sync on a machine without harness Python.
4. S4-9 (APFS) is real but minor. I recommend exact matching on macOS and Linux and case-insensitive matching on Windows only.
5. The first-run-without-node claim in §8 "Bootstrap" holds. Installer Step 1 (gh) runs before Step 8 (node), and no dotprofile exists before `aitools user init`. Independence caveat: the same author wrote S3-Gate-A (no Agent tool in this session).

## INCIDENT markers (not filed)

- INCIDENT (high): in today's code, the managed-file `[x]abort` (`prompt_diff_review` / `prompt_json_field_review`, `exit 2`) cannot be told apart from bash's own exit 2 on a `set -e` death (probes e1-e3). This sharpens S4 draft #87: the fix for #87 must use a marker, not just honour exit 2.
- INCIDENT (low): `ensure_tool_on_path` in `aitools-lib.sh` does `local known_paths=("$@")` and then `for kp in "${known_paths[@]}"`. Called with no paths under `set -u` on bash 3.2, it crashes (probe c3 pattern). Today's callers always pass paths (unverified across all callers).
