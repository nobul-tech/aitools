## Assumptions

- **ACTION pairing level (I-2 / #147 not decided):** each section-1 ACTION accompanies an ERROR row, so its log line is `log_error` / `LogError`. This counts one more error on those paths (exit was already 1; the footer says "FAILED with N+1 error(s)"). Not `log_warn`: that would count a warning and auto-promote later OK rows. Section 3 keeps its existing `log_warn` pairing (its row is OK/WARN).
- **No version value in "is not v2":** I tried `(version X)`. A probe of 14 values showed the two engines print some numbers differently (`1e2` -> `1e2` vs `100`, `-0` vs `0`), which would add a parity gap. So the message carries no value.
- **A v2 file without a profiles object stays "invalid"**, with or without `--no-machine`, as the launch prompt and #98 say. `register` would repair it (it writes `profiles: {}` when the key is not an object), so "Run: aitools user init" is defensible advice; see Follow-ups.
- **Case twin: no ACTION row.** The error line names the key. An ACTION could co-occur with a section-1 ACTION and break "at most one ACTION".
