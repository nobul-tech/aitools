build-package · Windows Intune package · decision P-8

Accept Microsoft's Win32 Content Prep Tool licence for nobul-tech CI

Intune Win32 packages (.intunewin) can only be built with Microsoft's IntuneWinAppUtil.exe, which runs on Windows. The plan uses it only inside GitHub Actions on a Windows runner. Its README says downloading and using it accepts its licence terms, so someone has to accept them for nobul-tech. That is you.

What you are agreeing to

  • Allowed: installing and using any number of copies.
  • Not allowed 4(e): sharing, publishing, renting or lending the tool. We never commit, cache, upload or bundle the exe.
  • Not allowed 4(a): working around its technical limits (so no patching it, and we don't run it under Wine).
  • Not allowed 4(b): reverse engineering, decompiling or disassembling it.
  • 3 The tool may send telemetry to Microsoft.

Source: the licence PDF in Microsoft's repo, read in full by two delegates (plans/build-package/mdm-windows-tool-findings.md, section 2.5). Not legal advice.

What aitools does with it

  • Each CI job downloads the exe fresh from Microsoft's own repo at a pinned commit (1d6cfcb, v1.8.7).
  • It checks the file's SHA-256 against our recorded value and its Authenticode signature before running it.
  • Impersonation repos exist on GitHub with fake "releases"; nothing is ever fetched from anywhere else.
  • Non-Windows machines don't run it; they start the Windows CI job and download the finished package.

Your three steps

  1. Open the licence: github.com/microsoft/Microsoft-Win32-Content-Prep-Tool (the licence PDF is in the repo root).
  2. Skim clauses 3 and 4 (the five points above).
  3. Paste this line into the Claude Code session. I record it as decision P-8 in plans/build-package/design.md.
I accept the Microsoft Win32 Content Prep Tool licence terms for nobul-tech CI use (v1.8.7, commit 1d6cfcb): download per job, never redistribute, commit, cache or modify it.

Not deciding yet is fine: the Windows build batch (B9a) waits on this line, and nothing downloads the tool until then.
