**R874d-28: What should the running-estimates directory in the dotprofile be called, and how should it be laid out?** (AMB-10)

D874d-52: "there should be a directory called "running estimates"". A space in a directory name has to be quoted in every shell command and script that touches it. The session archives sit one directory per project: `sessions/<project>/<YYYY-MM-DD>_<p8>.jsonl`.

Suggest:
- name the directory `running-estimates/`;
- lay it out like the archives: `<dotprofile>/running-estimates/<project>/<YYYY-MM-DD>_<session id prefix>.json`, for example `running-estimates/aitools/2026-11-15_dbd05b0c-2.json`.
