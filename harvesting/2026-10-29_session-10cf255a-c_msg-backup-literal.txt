Use -LiteralPath in Backup-File and Backup-Dir

With -Path, a file name containing [ ] is a wildcard: Test-Path returned
false, so the file got no backup while Backup-File reported success
($script:BackupFileOk stayed true). Deploy-ManagedFile relies on it.
Backup-File now uses -LiteralPath for Test-Path, Copy-Item and Remove-Item,
and prunes by a literal name prefix instead of a wildcard. Backup-Dir had
the same pattern in Test-Path, Get-ChildItem and Copy-Item.
