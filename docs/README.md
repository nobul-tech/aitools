# Documentation

Vendor documentation (PDFs and other formats) and their corresponding markdown conversions, organized by vendor.

## Contents

| Directory | Description |
|-----------|-------------|
| `quantum/` | Quantum StorNext documentation (PDFs + Marker-converted markdown) |

Each vendor subdirectory contains source files (PDFs, etc.) and their converted markdown equivalents. Conversions use [Marker](https://github.com/VikParuchuri/marker) -- see `conversionutils/COMPARISON_REPORT.md` for the quality comparison that led to this choice.
